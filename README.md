I'm Vyu, the developer behind NoteXI. I designed and built this notepad application as a teenager in my late 14's, with the goal of bringing simple note-taking and useful everyday utilities together in one place.

NoteXI is a personal project built with curiosity, creativity, and a passion for programming. What started as an idea grew into a working Windows application, developed one feature at a time.

What is NoteXI?

NoteXI aims to make everyday tasks easier by combining a notepad with practical utilities in a single application.
